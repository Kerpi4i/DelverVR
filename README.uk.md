# Delver VR

Неофіційний PC VR-мод для Steam-версії Delver: відстеження гарнітури й рук, взаємодія з предметами, фізичний бій, хотбар на лівій руці, карта на правій та стандартний інвентар із VR-вказівником.

**[Завантажити інсталятор](https://github.com/Kerpi4i/DelverVR/releases)** · [English](README.md)

Це публічна beta, перевірена переважно з Quest 2 і Touch через PC та SteamVR. Це не автономний APK. Інші гарнітури та сторонні моди потребують перевірки. Тіні можуть суттєво знижувати FPS.

## Встановлення

1. Потрібні Windows 10/11 x64, Steam-версія Delver зі штатним Java та SteamVR.
2. Запустіть `DelverVR-Setup-0.2.0.exe` зі сторінки Releases.
3. Виберіть папку гри з `delver.jar` і `jre-x64-windows`.
4. Інсталятор створить підпапку `DelverVR` і локальні патчі. Оригінальні файли не перезаписуються. Для Program Files Windows може запросити права адміністратора.
5. Підключіть гарнітуру до ПК, запустіть SteamVR та `<папка гри>\DelverVR\DelverVR.exe`. Гра стартує одразу, без меню лаунчера.

Гравцеві не потрібно встановлювати JDK, Python чи запускати PowerShell. Інсталятор beta не підписаний цифровим сертифікатом; Windows може показати невідомого видавця. Завантажуйте зі сторінки релізу й звіряйте SHA256 з `SHA256SUMS.txt`.

## Додати до SteamVR

Steam → Ігри → Додати сторонню гру → Огляд → вибрати встановлений `DelverVR.exe`. Назвіть ярлик «Delver VR». У властивостях увімкніть «Include in VR Library» / «Додати до бібліотеки VR», якщо цей параметр доступний. Запускайте ярлик із бібліотеки SteamVR, без додаткових параметрів запуску.

Параметр VR-ярлика залежить від версії Steam. EXE також можна запустити напряму при активному SteamVR. Досягнення та Workshop API цим ярликом не підключаються.

## Керування Touch (локальна тестова збірка)

| Дія | Керування |
|---|---|
| Рух / драбини | Лівий стік; убік — зійти з драбини |
| Поворот | Правий стік ліворуч/праворуч |
| Центрування | Клік правого стіка |
| Карта | A |
| Хотбар | X |
| Інвентар / вихід з інвентаря | Y |
| Меню | B |
| Взяти / відпустити предмет | Нижній курок (grip); біля тіла — зберегти, під час руху — кинути |
| Підібрати / застосувати / запалити бомбу в руці | Верхній курок (trigger) |
| Навігація інвентарем | Промінь правої руки; trigger — клік або утримання для перетягування |
| Вибрати слот хотбару | Навести або торкнутися, натиснути grip/trigger |
| Лук | Натягнути іншою рукою, відпустити trigger |

У Налаштування > VR окремо для карти й хотбару: завжди показувати, при утриманні кнопки або перемикати натисканням. За замовчуванням — утримання A/X. Там само є вибір кистей чи повних рук. Тривалість активних ефектів показується в інвентарі.


## Збереження й видалення

Збереження: `%LOCALAPPDATA%\DelverVR\save`.
Журнал гри: `%LOCALAPPDATA%\DelverVR\delver-vr.log`.
Журнал встановлення: `%LOCALAPPDATA%\DelverVR\installer.log`.

Для перенесення з розробницької збірки скопіюйте вміст її `dist\vr-save\save` у нову папку при закритій грі. Спочатку зробіть резервні копії.

Для видалення запустіть `DelverVR-Uninstall.exe` у папці мода. Збереження, оригінальна гра та сторонні файли зберігаються. Ярлик Steam видаляється через Steam. Оновлення інсталятором зберігає попередню інсталяцію в `DelverVR.backup-*`; ці резервні копії автоматично не видаляються.

У пакеті немає платних даних Delver — вони використовуються з копії гравця. Збирання з вихідного коду: [README англійською](README.md). Помилки: [Issues](https://github.com/Kerpi4i/DelverVR/issues), із моделлю гарнітури, GPU, описом відтворення та журналом, перевіреним на приватні дані.

## Workshop

Підпишись на мод у Steam, дочекайся завершення завантаження й перезапусти Delver VR. PC-мод знаходить встановлений контент Workshop для Delver (249630) у бібліотеках Steam, а також каталог mods у папці гри. Копіювати моди вручну не потрібно. У штатному пункті Mods головного меню можна їх увімкнути/вимкнути; вибір зберігається окремо для VR. Прокручування списків — правим стіком вгору/вниз при наведенні вказівника.

Підписками й завантаженнями керує Steam. Інтеграція читає локально встановлений контент без Steam API гри; досягнення не підключає. Сумісність окремих модів та їхніх комбінацій у VR потребує перевірки. Автономний Quest-порт не шукає бібліотеки Steam на ПК.

Хотбар знову в один компактний ряд біля зап’ястя.

Локальна beta.9: верхній курок додатково використовує наведення поглядом для прихованих тригерів і штатну взаємодію зі спеціальними тайлами. До пошуку додано дочірні й прикріплені тригери. Змінено пріоритет динамічних джерел світла за їхньою яскравістю та радіусом; перевірка проблемних модових кімнат у гарнітурі ще потрібна.
