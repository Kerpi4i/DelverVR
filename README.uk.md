# Delver VR

Неофіційний PC VR-мод для Steam-версії Delver: відстеження гарнітури й рук, взаємодія з предметами, фізичний бій, хотбар на лівій руці, карта на правій та стандартний інвентар із VR-вказівником.

**[Завантажити інсталятор](https://github.com/Kerpi4i/DelverVR/releases)** · [English](README.md)

Це публічна beta, перевірена переважно з Quest 2 і Touch через PC та SteamVR. Це не автономний APK. Інші гарнітури та сторонні моди потребують перевірки. Тіні можуть суттєво знижувати FPS.

## Встановлення

1. Потрібні Windows 10/11 x64, Steam-версія Delver зі штатним Java та SteamVR.
2. Запустіть `DelverVR-Setup-0.2.0-beta.1.exe` зі сторінки Releases.
3. Виберіть папку гри з `delver.jar` і `jre-x64-windows`.
4. Інсталятор створить підпапку `DelverVR` і локальні патчі. Оригінальні файли не перезаписуються. Для Program Files Windows може запросити права адміністратора.
5. Підключіть гарнітуру до ПК, запустіть SteamVR та `<папка гри>\DelverVR\DelverVR.exe`. Гра стартує одразу, без меню лаунчера.

Гравцеві не потрібно встановлювати JDK, Python чи запускати PowerShell. Інсталятор beta не підписаний цифровим сертифікатом; Windows може показати невідомого видавця. Завантажуйте зі сторінки релізу й звіряйте SHA256 з `SHA256SUMS.txt`.

## Додати до SteamVR

Steam → Ігри → Додати сторонню гру → Огляд → вибрати встановлений `DelverVR.exe`. Назвіть ярлик «Delver VR». У властивостях увімкніть «Include in VR Library» / «Додати до бібліотеки VR», якщо цей параметр доступний. Запускайте ярлик із бібліотеки SteamVR, без додаткових параметрів запуску.

Параметр VR-ярлика залежить від версії Steam. EXE також можна запустити напряму при активному SteamVR. Досягнення та Workshop API цим ярликом не підключаються.

## Керування Touch

| Дія | Керування |
|---|---|
| Ходьба | Лівий стік за напрямком голови |
| Поворот на 30° | Правий стік убік |
| Відкрити інвентар | BAG біля хотбару лівої руки, grip/trigger правої |
| Навігація інтерфейсом | Промінь правої руки, trigger; утримання — перетягування |
| Взяти предмет / слот хотбару | Grip |
| Зберегти / кинути | Відпустити grip біля тіла / під час кидка |
| Застосувати предмет | Trigger; рухи руки для ближнього бою |
| Лук | Тримати лук, натягнути іншою рукою, відпустити trigger |
| Драбини | Лівий стік вперед/назад; убік — зійти |
| Меню / закрити інвентар | Ліва X / дія меню |
| Центрування | Права A |

## Збереження й видалення

Збереження: `%LOCALAPPDATA%\DelverVR\save`.
Журнал гри: `%LOCALAPPDATA%\DelverVR\delver-vr.log`.
Журнал встановлення: `%LOCALAPPDATA%\DelverVR\installer.log`.

Для перенесення з розробницької збірки скопіюйте вміст її `dist\vr-save\save` у нову папку при закритій грі. Спочатку зробіть резервні копії.

Для видалення запустіть `DelverVR-Uninstall.exe` у папці мода. Збереження, оригінальна гра та сторонні файли зберігаються. Ярлик Steam видаляється через Steam. Оновлення інсталятором зберігає попередню інсталяцію в `DelverVR.backup-*`; ці резервні копії автоматично не видаляються.
